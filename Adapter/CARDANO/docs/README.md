# Cardano Adapter Documentation

Cardano is the current execution adapter for IMMORTAL.

The adapter maps universal concepts to Cardano mechanisms. It does not redefine IMMORTAL semantics.

See:

- [Adapter Specification](ADAPTER-SPECIFICATION.md)
- [IMMORTAL documentation](../../../docs/README.md)
- [PRE-RICH application](../../../PRE-RICH/docs/README.md)

Cardano-specific implementation assumptions belong here rather than in the universal protocol specification.
