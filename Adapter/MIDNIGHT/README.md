# IMMORTAL — Midnight Adapter Research Surface

Research-only. The repository currently has one concrete adapter: Cardano.

This directory investigates a future Midnight Adapter without importing Cardano runtime types into the Midnight boundary.

Current target:

IMMORTAL IssueIntent
→ chain-neutral Economic Admission
→ Midnight execution envelope
→ Compact circuit + witness/private state
→ Midnight ledger / ZK proof
→ observed public state
→ execution evidence

Important: this surface does not define a production economic rule, a new authority path, or a new settlement policy.

Historical source note: the project refers to a language named Miroarty as the origin of the Intent concept, but that source has not yet been recovered or externally verified. Compact is the currently verified Midnight language target.
