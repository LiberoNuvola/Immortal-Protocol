# PRE-RICH — Application Roadmap

**Parent protocol:** IMMORTAL v3.0.0  
**Current adapter:** Cardano

This roadmap covers PRE-RICH application work only. It does not redefine IMMORTAL.

## 1. Application foundation

- Open-source application structure
- Application documentation aligned with IMMORTAL
- Explicit application policy register
- Clear separation between current behavior, target architecture and open policy

## 2. Scratch & Win

- economic policy/specification closure
- state-machine conformance
- cryptographic core validation
- economic implementation conformance
- deterministic replay/test evidence
- expiry and crystallized-right validation

## 3. Beacon evolution

### B1 — Authorized Publisher
Current application architecture.

### B3 — publisher-independent canonicality
Target architecture requiring its own implementation and evidence.

## 4. Mainnet readiness

Mainnet readiness is a deployment gate, not a documentation label. It requires the relevant implementation, adapter, security, operational and conformance evidence.

## 5. Community and governance

Application governance must remain distinct from ownership and must not bypass IMMORTAL mandatory safety predicates.
