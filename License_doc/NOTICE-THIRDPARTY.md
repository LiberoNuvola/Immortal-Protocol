# IMMORTAL Protocol --- Third-Party Notices

This file records the repository-level rule for third-party material.

Third-party code, libraries, generated assets, fonts, icons, datasets,
examples, and other material remain subject to their respective upstream
licenses and notices. Inclusion in this repository does not relicense
that material under the IMMORTAL Protocol software or documentation
licenses.

In particular:

-   Preserve upstream copyright notices and license texts where
    required.
-   Preserve package-level license metadata.
-   Do not remove attribution or NOTICE files supplied by dependencies.
-   `blockfrost-proxy` is separately identified as ISC in its package
    metadata.
-   Dependency-specific notices should be added here or in the relevant
    component directory when the dependency's license requires an
    explicit notice.

This repository-level notice is intentionally non-exhaustive. The
dependency manifests and their upstream license files are authoritative
for the specific third-party components.
