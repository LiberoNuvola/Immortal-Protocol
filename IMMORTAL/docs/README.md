# IMMORTAL Core Documentation

This directory contains documentation placed next to the IMMORTAL reference implementation and formal core.

It is implementation-oriented.

For canonical universal normative authority, use the repository-level [`docs/00-normative/`](../../docs/00-normative/) corpus.

## Core implementation areas

- `kernel/` — economic kernel/reference logic
- `state/` — canonical economic state
- `conformance/` — conformance/reference vectors

The presence of implementation code does not by itself establish conformance. See the repository-level conformance and audit documents.
