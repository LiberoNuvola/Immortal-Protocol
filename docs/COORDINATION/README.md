## Recent

## Rules

- Every operational handoff must be dated in its filename or header.
- Every coordination document must state that it is non-normative.
- Stable closure belongs under `docs/03-audit/`.
- Coordination files must not be cited as certification evidence.
- When a coordination note conflicts with a higher authority, correct the note rather than changing protocol semantics.
