# IMMORTAL Experimental Declaration

IMMORTAL is an experimental open-source protocol.

This declaration is intentionally explicit:

- IMMORTAL is not presented as a finished production protocol.
- The repository is not, by publication alone, a security certification.
- Formal proofs concern stated mathematical models and assumptions.
- Implementation conformance requires separate evidence.
- Adapter conformance requires separate evidence.
- Application correctness requires separate evidence.
- Deployment safety requires deployment-specific evidence.
- There is no claim that a permanent team, privileged operator or unilateral stakeholder is required by the protocol.
- Governance is an evolution mechanism, not ownership.
- Forks, competing implementations and independent verification remain possible.

The current repository contains research, implementation and documentation at different maturity levels. Each artifact must retain its declared status.
