# Code of Conduct

## Commitment

IMMORTAL is an open-source experimental project intended for public technical review, research and contribution.

We expect participants to:

- communicate respectfully;
- criticize ideas, code and evidence rather than people;
- welcome technical disagreement;
- distinguish evidence from assumptions;
- disclose relevant conflicts where appropriate;
- respect responsible security disclosure.

Unacceptable behavior includes harassment, threats, discrimination, personal attacks, malicious disruption and deliberate presentation of false technical claims as established facts.

Project maintainers may moderate participation where necessary to protect contributors and project infrastructure.

This code applies to repository discussions, issues, pull requests and other project spaces maintained for IMMORTAL development.
